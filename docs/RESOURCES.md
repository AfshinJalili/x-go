# Go Interview Resources

## Knowledge

- [A Tour of Go](https://go.dev/tour/)
  Interactive official intro. Use for: types, methods, interfaces, concurrency warm-up.
- [Effective Go](https://go.dev/doc/effective_go)
  Idiomatic style guide (older; still strong on core patterns). Use for: receivers, interfaces, concurrency habits.
- [The Go Programming Language Specification](https://go.dev/ref/spec)
  Authoritative language rules. Use for: zero values, method sets, channel ops, type rules.
- [Go Blog: Go Slices: usage and internals](https://go.dev/blog/slices-intro)
  Backing arrays, length, capacity. Use for: Hour 1 slice questions.
- [Go Blog: Laws of Reflection / Interfaces](https://go.dev/blog/laws-of-reflection) and [Go Blog: Errors are values](https://go.dev/blog/errors-are-values)
  Interface/error mental models. Use for: Hour 2.
- [Go Blog: Go Concurrency Patterns: Context](https://go.dev/blog/context) and [Go Blog: Pipelines](https://go.dev/blog/pipelines)
  Context + channel pipelines. Use for: Hour 3–4.
- [Package sync](https://pkg.go.dev/sync) / [Package context](https://pkg.go.dev/context) / [Package errors](https://pkg.go.dev/errors)
  API truth. Use when behavior must be precise.

## Wisdom (Communities)

- [r/golang](https://www.reddit.com/r/golang/)
  Broad Go community. Use for: design questions, interview war stories — filter noise.
- [Gophers Slack](https://invite.slack.golangbridge.org/)
  Practitioners. Use for: “is this idiomatic?” sanity checks.
- Local: any Go meetup / interview mock with a peer
  Use for: verbal practice under time pressure (Hour 5 skill).
